# Contributing

Contributions, reproducible bug reports and GNOME compatibility test results are welcome. Please open an issue before proposing extensive API or schema changes. Include Ubuntu version, `gnome-shell --version`, installation method, reproduction steps and relevant GNOME Shell logs. Run `./scripts/check.sh` and explain any checks that could not run.

**Note:** The maintainer has not yet selected a public source-code license. Contributors should clarify licensing and permissions with the maintainer before submitting patches intended for public redistribution. Do not upload original Fliqlo fonts, binaries or extracted proprietary assets.
