# Security

This extension runs inside GNOME Shell. Please avoid posting exploit details publicly before the maintainer can investigate. Contact the repository maintainer privately using the contact route on their GitHub profile, or open a GitHub private vulnerability report if enabled. Do not share passwords, user files or proprietary fonts in bug reports.

The screensaver is **not** a security lock. It does not replace GNOME's authentication screen and must yield immediately when GNOME locks or blanks the display.
