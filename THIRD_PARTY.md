Fliqlo is created by Yuji Adachi / 9031: https://fliqlo.com/.
This is an independent Ubuntu implementation, not an official Fliqlo release.

The uploaded macOS DMG and Windows ZIP were inspected locally as reference material. Their
executables, embedded HTML, fonts, thumbnails, and other original assets are not included in
this repository or Debian package. Font import operates only on a file
selected by the user and installs it in that user's local font directory.

GTK, GLib, Cairo, Pango, GNOME Shell, fontconfig, fontTools, Brotli, and DejaVu fonts are supplied by
Ubuntu packages and retain their respective licenses. 7-Zip and Rizin were
used as external local analysis tools and are not bundled. Evidence files
retain tool output and artifact identities; see research/evidence/ANALYSIS.md.
